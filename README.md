# Mooring

> Documentation woven for EFT.

Mooring is a documentation tool built specifically for ICEEFT-certified and EFT-trained couples clinicians. This repository contains the static landing page.

## The Problem

Generalist AI scribes capture words but miss the work. They don't recognise attachment cycles, can't distinguish primary from secondary emotion, and have no concept of Tango moves or stage progression. Notes come back generic — and you end up rewriting them.

## The Approach

Mooring is being built specifically for ICEEFT-certified and EFT-trained couples clinicians. The thread metaphor isn't decorative: documentation should reflect how the model actually moves — cycles, primary emotion underneath secondary, the progression through stages.

Built by someone with both clinical and engineering backgrounds, with the model trained on the framework you actually use.

## Running Locally

This is a plain HTML static site. To preview it locally, open [`index.html`](./index.html) directly in a browser, or serve it with any static file server:

```bash
npx serve .
```

or

```bash
python3 -m http.server
```
